异星工厂 版本 2.0.77 稳定版发布

异星工厂版本 2.0.77 稳定版现已发布，带来了多项错误修复和面向模组制作者的脚本 API 更新。修复了包括货运舱夹模、机械臂死锁以及各种崩溃问题。

主要改动

  • 异星工厂版本 2.0.77 稳定版发布
  • 修复了多处错误和崩溃问题
  • 为脚本 API 添加了多项新的读取属性
  • 在线 API 文档网站支持全文搜索

错误修复

  • 修复了火箭所附货运舱的穿模问题
  • 修复了机械臂在向炮塔挥动途中弹药变质导致的死锁问题
  • 修复了因模组更改导致火箭发射井死锁的问题
  • 修复了特定实体在无来源被击杀时的崩溃问题
  • 修复了多人游戏延迟期间个人资料库蓝图书滚动不正常的问题
