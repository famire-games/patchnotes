3. 광고와 쿠키

사이트는 운영비를 위해 Google AdSense 광고를 게재할 수 있습니다. Google 등 제3자 광고 업체는 쿠키를 사용해 이용자의 이전 방문 기록을 바탕으로 광고를 보여 줄 수 있습니다. 맞춤 광고는 Google 광고 설정에서 끌 수 있으며, 브라우저 설정에서 쿠키 저장을 거부할 수 있습니다. 사이트는 게임 데이터(블리자드 등)를 광고 대상 설정에 사용하지 않습니다.

4. 게임 데이터

사이트의 게임 정보는 각 게임사의 공개 자료와 공식 API(Blizzard Battle.net API, Riot Games Data Dragon, Steam Web API, PokeAPI 등)에서 가져온 것으로, 이용자 개인의 게임 계정 정보는 수집하지 않습니다. 블리자드 API 데이터는 "있는 그대로" 제공되며 정확성이나 가용성을 보장하지 않습니다. 블리자드 API 데이터는 30일 이내 주기로 갱신합니다.

5. 이용자의 권리

이용자는 언제든지 자신의 정보 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 즐겨찾기는 사이트에서 직접 지울 수 있고, 계정 정보 전체 삭제는 아래 연락처로 요청하면 지체 없이 처리합니다. 만 14세 미만 아동은 로그인 기능을 이용할 수 없으며, 사이트는 13세 미만을 대상으로 하지 않습니다.

6. 안전성 확보 조치

즐겨찾기 데이터는 본인만 읽고 쓸 수 있도록 접근 규칙을 설정해 두었으며, 모든 통신은 HTTPS 로 암호화됩니다. 개인정보 유출이 확인되면 관련 법령에 따라 이용자와 관계 기관에 알립니다.
