1/29(목) 업데이트 패치 내역

1월 29일 메이플스토리 월드 업데이트가 진행되었습니다. 클라이언트 버전 표기 방식 변경 및 프로필 코드 6자리 확대, 로비 UI 개선, 일본어 자동 번역 추가 등이 적용되었습니다. 또한 각종 오류가 수정되었습니다.

주요 변경

  • 클라이언트 정규 업데이트 버전 표기 방식 변경 (연도.월 기준)
  • 무료 월드코인 획득 시 알림 기능 추가
  • 프로필 코드 기존 5자리에서 6자리로 확대
  • 로비 화면에서 월드가 최대 10개까지 노출되도록 개선
  • 자동 번역 지원 언어에 '일본어' 추가

버그 수정

  • 클라이언트 실행 시 간헐적으로 해상도가 잘못 설정되던 현상 수정
  • iOS 환경에서 언어 변경 시 간헐적으로 로그아웃이 안 되던 현상 수정
  • 아바타 상점에서 부위별 탭 이동 버튼이 정상 동작하지 않던 현상 수정
  • 월드 검색 시 '#' 포함 시 네트워크 오류가 발생하던 현상 수정
  • 친구 초대 이벤트에서 초대 코드 입력 오류 현상 수정
