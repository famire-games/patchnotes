4/24(목) 메이플스토리 월드 업데이트 안내

메이플스토리 월드 1.24.0 버전 업데이트가 4월 24일 진행되었습니다. 중국어(번체) 지원, 쿠폰 기능, 크리에이터 상품 환불 요청 기능 및 다양한 편의성 개선과 오류 수정이 이루어졌습니다.

주요 변경

  • 월드 및 클라이언트 지원 언어에 '중국어(번체)' 추가
  • 쿠폰 번호 입력 및 보상 획득 기능 추가 (iOS는 공식 홈페이지 이용)
  • 크리에이터 제작 상품 환불 요청 기능 추가 (월드코인 내역에서 7일간 노출)
  • 아바타 상점에서 제작자명을 클릭하여 프로필 페이지 확인 가능
  • 공식 홈페이지에서 프리미엄 PC방 접속 여부 아이콘 확인 가능
  • PC방 보상 팝업 활성화 상태에서 날짜 변경 시 보상 목록 즉시 갱신

버그 수정

  • 제재된 플레이어가 테스트 서버 입장 시도 시 제재 팝업이 노출되지 않던 현상 수정
  • 공식 홈페이지에서 월드 플레이 입장 후 로비 이동 시 간헐적으로 월드코인 보유량이 음수로 표시되던 현상 수정
  • 월드 내 상점에서 판매되는 상품 명칭이 월드 언어 기준으로 번역되도록 수정
