10월 7일(수) 업데이트 패치 안내

메이플스토리 월드 10월 7일 점검 패치 내역입니다. 클라이언트 로비에서 ESC 키로 종료가 가능해지고 창 모드 해상도 설정이 개선되었으며, 모바일 상점 오류 및 화면 해상도 관련 버그가 수정되었습니다.

주요 변경

  • 클라이언트 로비에서 ESC 키로 종료 기능 추가
  • 창 모드 월드 플레이 시 [설정-그래픽] 지정 해상도 적용
  • 모바일 환경 아바타 상점 필터 변경 시 요청 실패 현상 수정
  • 아바타 상세 정보에서 '판매 중인 상품 보기' 시 미리보기 해제 현상 수정
  • 최대화 모드로 월드 진입 시 해상도 변경 현상 수정

버그 수정

  • 모바일 아바타 상점 필터 변경 시 요청 실패 메시지 노출 오류 수정
  • 아바타 상세 정보에서 '판매 중인 상품 보기' 선택 시 미리보기 아바타가 임의로 해제되던 오류 수정
  • 최대화 모드로 월드 진입 시 최대화 모드가 해제되며 화면 해상도가 변경되던 오류 수정
