클라이언트 1.2.419(5) 업데이트

메이플스토리 클라이언트 1.2.419(5) 업데이트가 진행되었습니다. 주로 직업 스킬 관련 오류와 몬스터 컬렉션 마일리지 관련 오류가 수정되었습니다.

주요 변경

  • 에르다 노바 사용 시 응축된 에르다 개수가 감소하지 않는 현상 수정
  • 미하일 로얄 가드 방어 가능 시간 증가 오류 수정
  • 윈드브레이커 하울링 게일 다수 적 공격 횟수 초과 현상 수정
  • 데몬 어벤져 익시드 엑스큐션 액션 딜레이 오류 수정
  • 몬스터 컬렉션 마일리지 1000 아이템 사용 오류 및 소실 조치 완료

상향

  • 감속 디버프가 적용되지 않는 몬스터에게 슬로우 효과 적용 시 데몬 슬레이어의 이블 토쳐가 정상 적용되도록 변경

하향

  • 윈드브레이커의 하울링 게일이 다수의 적을 공격할 때 최대 공격 횟수를 초과하여 공격하던 현상 수정
  • 데몬 어벤져의 익시드 : 엑스큐션 3, 4단계일 때 액션 딜레이가 의도보다 감소되어 있던 현상 수정

버그 수정

  • 에르다 노바를 스틱스, 플레게톤 감응 스킬로 등록할 수 없는 오류 수정
  • 나이트워커 다크니스 어센션이 재사용 대기시간 중 맵 이동 시 발동되는 현상 수정
  • 메카닉 메탈아머: 탱크 탑승 중 엎드린 상태에서 제트 부스터 메카닉 대쉬 사용 현상 수정
  • 몬스터 컬렉션 과거의 문 페이지 완성 보상 마일리지 1000 아이템 사용 시 탐험 코인을 획득할 수 없는 현상 수정
