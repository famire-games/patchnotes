카운터 스트라이크 2 업데이트

이번 카운터 스트라이크 2 업데이트에서는 소리 없는 재장전 모드의 조작 옵션이 추가되고 관련 버그들이 수정되었습니다. 또한 AMD 그래픽 카드에서의 액터 렌더링 문제와 데모 재생 관련 버그가 해결되었습니다.

주요 변경

  • 소리 없는 재장전 모드(누르기/토글) 옵션 추가
  • 토글 활성화 시 재장전 버튼을 떼어도 소리 없는 재장전 유지 가능
  • 재장전 버튼을 다시 눌러 소리 없는 재장전을 취소하고 빠른 재장전으로 전환 가능
  • AMD 그래픽 카드에서 액체 그래픽이 검은색으로 렌더링되던 버그 수정
  • 데모 재생 중 되감기 시 발생하는 사운드 및 UI 버그 수정

버그 수정

  • 요청 여부와 관계없이 재장전의 첫 번째 소리가 들리던 다양한 경우 수정
  • AMD 그래픽 카드에서 액체가 검은색으로 렌더링되던 버그 수정
  • 데모 재생 중 되감기 시 발생하는 사운드 및 UI 버그 수정
