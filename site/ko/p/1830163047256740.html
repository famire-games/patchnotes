스트리노바 4월 16일 업데이트

신규 폭파전 맵 '르브런 시티'가 추가되었으며, 맵 워크숍 내 '붐 페스트' 모드와 축구 키트 모듈이 도입되었습니다. 또한 씨엘, 바이모 등 캐릭터 밸런스 조정 및 무기 분산도 개선이 이루어졌습니다.

주요 변경

  • 신규 폭파전 맵 '르브런 시티' 추가
  • 맵 워크숍 '붐 페스트' 및 축구 키트 모듈 추가
  • 카드 시스템 확장 및 데크 생성 가능 갯수 6개에서 9개로 증가
  • 전체 무기 및 일부 캐릭터(씨엘, 바이모) 밸런스 조정
  • 신규 이벤트(코스믹 초대장, 르브런 시티 탐험 등) 진행
  • 헤르메스 상점 신규 스킨 및 오르빛 공명 업데이트

상향

  • 슈퍼스트링 모드에서 피해를 줄 때 XP 획득 속도 상향
  • 레벨업당 기존 +5% 데이징에서 +5% 무기 데미지로 변경
  • 검투(Sword Clash) 극한 폭발 시 근접 공격 속도 100% 증가
  • 씨엘 스트링 에너지 네트워크 각성 3 피해 전파 계수 상향 (1.25 -> 1.33)
  • 바이모 스트링 에너지 네트워크 각성 2 피해 감소 지속 시간 증가 (0.6초 -> 0.75초)
  • 바이모 얼티밋 사용 후 복귀 시 남은 위치에 강화된 수류탄 생성 기능 추가

하향

  • 블래스트 피엔드의 자폭 궁극기로 아머 포저 카드 효과를 발동할 수 없도록 수정
  • 씨엘 기본 무기 기본 피해량 감소 (136 -> 120, 발사 속도 100 -> 105로 조정)
  • 바이모 스트링 에너지 네트워크 각성 3 은폐 지속 시간 감소 (0.6초 -> 0.5초)

버그 수정

  • 맵 워크숍 방어 타워 모듈의 피해 배율 설정이 적용되지 않던 문제 수정
  • 노부나가 순간이동 시전 시간이 특수 조작으로 취소되던 문제 수정
  • 특정 지역(오일러 항구, 심연의 전선 등)에서 캐릭터가 끼이거나 비무적 상태가 되던 문제 수정
  • 카나미 Azure Specter 스킨의 현현 상태 비정상 동공 효과 수정
  • 로비 미리보기에서 특정 스프레이 소리가 너무 크게 재생되던 문제 수정
