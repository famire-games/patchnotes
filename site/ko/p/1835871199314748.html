팩토리오 버전 2.0.77 안정 버전 출시

팩토리오 버전 2.0.77 안정 버전이 출시되어 다양한 버그 수정과 모드 제작자를 위한 스크립팅 API 기능이 추가되었습니다. 로켓 화물 포드 클리핑 문제, 투입기 교착 상태 등 플레이 안정성을 저해하는 오류들이 해결되었습니다.

주요 변경

  • 버전 2.0.77 안정 버전 출시
  • 다양한 버그 및 충돌 현상 수정
  • 스크립팅 API에 새로운 읽기 전용 속성 대거 추가
  • API 문서 웹사이트 전체 텍스트 검색 지원

버그 수정

  • 로켓에 부착된 화물 포드의 클리핑 문제 수정
  • 포탑을 향해 스윙 중 탄약이 상해버릴 때 투입기가 교착 상태에 빠지는 현상 수정
  • 모드 변경으로 인해 로켓 사일로가 교착 상태에 빠지는 현상 수정
  • 출처 없이 특정 엔티티가 파괴될 때 발생하는 게임 종료 현상 수정
  • 멀티플레이어 지연 시간 동안 개인 라이브러리 청사진북 스크롤이 제대로 작동하지 않던 문제 수정
