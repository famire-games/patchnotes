스타듀 밸리 1.6.15 패치 배포

스타듀 밸리 1.6.15 패치가 배포되었습니다. 전설의 물고기 연못 상향, 냉장고 UI 내 꾸러미 버튼 추가를 비롯한 다양한 편의성 개선과 버그 수정이 이루어졌습니다.

주요 변경

  • 전설의 물고기 연못 생산성 상향
  • 냉장고 및 미니 냉장고 UI에 주니모 꾸러미 버튼 추가
  • 게임 성능 최적화
  • 일부 플랫폼의 불필요한 금칙어 필터링 제거
  • 일본어 플레이어의 금요일 크로버스 상점 접근 불가 문제 수정
  • 멀티플레이어 및 모드 관련 다수 오류 수정

상향

  • 전설의 물고기 연못에서 어란을 훨씬 더 자주 생산하며 평균 일일 가치가 증가함

버그 수정

  • 크로버스의 상점에 금요일에 접근할 수 없던 문제 수정
  • 새 게임 생성 전 로드 화면을 볼 때 드물게 데이터가 잘못 복사되던 데이터 손상 문제 수정
  • 빈 통발을 수거할 때 발생하던 충돌 수정
  • 농장 동물이 여러 지역에 동시에 존재할 때 발생하던 충돌 수정
  • 농장 보조 일꾼이 장소를 이동하는 도중 쓰러질 때 발생하던 충돌 수정
