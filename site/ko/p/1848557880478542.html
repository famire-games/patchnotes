11/4 핫픽스 업데이트

"인 더 정글" DLC의 미니게임 시스템이 개선되었으며, 사격장 그래픽 깨짐 및 낚싯대 설명 누락 등 여러 버그가 수정되었습니다. 이번 업데이트는 윈도우와 맥 버전 모두에 적용됩니다.

주요 변경

  • 미니게임: 도감에 등록되지 않은 딱정벌레 배틀 곤충의 등장 빈도 상향
  • 사격장: 림보의 사격장에서 화면 그래픽이 깨지던 문제 수정
  • 낚시: 우타라 낚싯대 설명 누락 수정 (동시에 두 마리 포획 가능 기능)
  • 캐릭터: 마틴 트위드 대화 중 홍보 영상이 재생되지 않던 문제 수정
  • 캐릭터: 하르타에게 좋아하는 선물 전달 시 대화 하이라이트 색상 오류 수정

상향

  • 미니게임 내 미등록 곤충 등장 빈도 증가

버그 수정

  • 림보의 사격장 화면 그래픽 깨짐 현상 수정
  • 우타라 낚싯대 기능 설명 누락 수정
  • 마틴 트위드 대화 중 홍보 영상 미재생 문제 수정
  • 하르타 선물 전달 시 대화 하이라이트 색상 오류 수정
