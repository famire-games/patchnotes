Team Fortress 2 Update

An update including gameplay improvements and bug fixes has been applied to Team Fortress 2. It includes Le Sapeur smoke effects, map adjustments, Halloween-related bug fixes, and Zombie Infection mode fixes.

Key changes

  • Fixed Le Sapeur smoke effect regression
  • Fixed clipping issues for certain cosmetic items
  • Added 1 minute to cp_wildcat_event map round timer
  • Fixed capture speed and ÜberCharge display bugs related to pumpkin disguises
  • General optimization and fixes for various Zombie maps
  • Changed Zombie Sniper's spit to deal critical hits to airborne enemies

Buffs

  • Added +1 minute to cp_wildcat_event round timer
  • Zombie Sniper's spit now applies critical hits to airborne targets
  • Added cover in front of the shack on zi_atoll and made the BLU spawn point permanently active

Bug fixes

  • Fixed a bug that allowed 15x speed captures while disguised as a pumpkin
  • Fixed a bug where buildings could be built inside the shutter doors of the connection between A and B
  • Fixed an issue where Jack-O'-Lanterns would not render during round setup times
  • Fixed a bug where Zombie Engineer building states were visible upon initial infection
  • Fixed an issue where the Reveal outline applied to players persisted into the next round
