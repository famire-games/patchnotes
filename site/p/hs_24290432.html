Hearthstone Patch 36.2 Notes

Hearthstone Patch 36.2 brings a new Battlegrounds season, small balance adjustments, the 'Rampage of Zuramat' event, and Darkmoon Faire Treasures. It also includes a Unity engine upgrade along with numerous bug fixes and improvements.

Key changes

  • New Battlegrounds season launched
  • Nerf to Demon Hunter card Feral Voidscale
  • 'Rampage of Zuramat!' in-game event
  • Heroic Tavern Brawl returns
  • Tanabata Turalyon and Alleria hero skins introduced
  • Unity engine upgrade and minimum system requirements update

Nerfs

  • Feral Voidscale

Bug fixes

  • Fixed visual bug where Krul the Unshackled's battlecry darkened the board until the end of the game
  • Fixed bug allowing Shadow of Doom to be played after playing a non-spell card with no valid effects
  • Fixed bug where Sinestra could cast the essence generated by Fragmented Dragon Soul twice
  • Fixed bug where playing two Mana Burns in the same turn applied only one effect
  • Fixed bug where Preparation abnormally triggered Agamaggan's effect
