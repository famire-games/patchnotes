Version 3.6 Update Notice

Wuthering Waves Version 3.6 introduces new Resonators Qingxi and Jinglan, along with the new area 'Xianwon Region' and Main Quest Chapter 4, Act 3. It also brings exploration motorcycle improvements, game optimizations, and various new events and challenges.

Key changes

  • Added new 5-star Resonators Qingxi (Aero/Longsword) and Jinglan (Fusion/Broadblade)
  • Added new 5-star weapons 'Mists of Dawn' and 'Heavenly Annihilation'
  • Added new area 'Xianwon Region' and Main Quest Chapter 4, Act 3
  • Improved exploration motorcycle navigation and autopilot mode
  • Upgraded PC version to support NVIDIA DLSS Frame Generation
  • Added new challenge 'Tactical Hologram: Sparring'
