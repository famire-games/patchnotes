War Sails Modding Kit & Patch WS v1.2.8 / BL v1.4.8

The War Sails Modding Kit for Mount & Blade II: Bannerlord is now available, alongside a new patch that fixes several crashes, adds corrupted file detection, and improves modding tools.

Key changes

  • War Sails Modding Kit released on Steam
  • Support for naval world maps and ship creation
  • Added corrupted game file detection and warnings
  • Shader compilation fallback system to prevent crashes

Bug fixes

  • Fixed crash related to deceased notables with caravans at sea
  • Fixed crash during War Sails storyline conversation with Gunnar
  • Fixed horse rein visual bug upon mounted agent death
  • Fixed jittering on ragdolls
  • Fixed decal removal bug in Multiplayer mission reset
