Phantasy Star Online 2 New Genesis · November 17, 2026

11/17 Server Maintenance and Bug Fixes

UTC 2026-11-18 02:00 ~ 08:00

Server maintenance for Phantasy Star Online 2 New Genesis (PSO2 NEW GENESIS ver.2) is scheduled, during which game access and events will be unavailable. Expirations for premium sets and storage items will be extended by the maintenance duration, and several bug fixes including Photon Bow and Dalio Ludian adjustments will be applied.

Key changes

  • Game access and events unavailable during maintenance
  • Expirations for premium sets and storage items extended by maintenance duration
  • Fixed Photon Bow Flex Arrow Tech Arts Customization Type 3 bug
  • Fixed Dalio Ludian boss battle part destruction and phase transition bugs
  • Fixed Legendios Harmonizer drop error in Trinitas and Trainia Advance

Bug fixes

  • Fixed a bug in Photon Bow PA Flex Arrow Tech Arts Customization Type 3 preventing Brave Spirit potency and PP recovery increase
  • Fixed Dalio Ludian second half boss battle part destruction bug under certain conditions
  • Fixed Dalio Ludian final phase transition delay bug
  • Fixed Legendios Harmonizer dropping instead of Legendios Harmonizer II in Trinitas: Geometric Labyrinth Rank 2 and Trainia Advance: Ordinal Tower Rank 8
