Tom Clancy's Rainbow Six Siege · November 3, 2026

Y11S3.3 and Upcoming Updates Notice

This is the Rainbow Six Siege Community Checkpoint notice. It includes the Legend Division, ranked map rotation changes, operator and gameplay balance adjustments, and plans for the Test Server and Hostage mode revamps.

Key changes

  • Introduction of 'Legend Division,' a permanent solo queue playlist exclusively for the Champion tier
  • Abolishment of seasonal ranked map rotations and transition to a fixed pool focused on top-tier maps (around 15)
  • Operator and gadget balance adjustments for Noor, Tachanka, Soliton Radar, Valkyrie, Capitão, and Clash
  • Preview of 'Half Reinforcements' and Hostage mode rework tests in the Y11S4 Test Server
  • Return of Hostage mode and Secure Area to Quick Match starting in Y11S4
  • Confirmed re-release of the popular 3v3 Arcade mode in Y11S4

Buffs

  • Noor: Horus Lance launcher reinforced surface/shield/hardened surface drilling time reduced (2s -> 1.5s), guard break intensity against shield operators increased (30% -> 100%), quickdraw animation equip time reduced (0.9s -> 0.4s), direct damage increased (50 -> 80)
  • Tachanka: Added mode switching to Shumikha Launcher (Impact mode that explodes on impact and Bounce mode that passes through glass/paper, etc.)
  • Valkyrie: Added Glaive-12 secondary weapon
  • Capitão: Fire spread interval shortened (1s -> 0.9s)
  • Clash: Movement speed reduction effect when running away enhanced (5% -> 10%)
  • OSA: Placement restrictions relaxed (reduced space requirements in front, vertically, and behind the player)
  • Fire damage increased (12HP -> 14HP)

Nerfs

  • Soliton Radar MK III: Precision charge count reduced (4 -> 3)

Bug fixes

  • Improved operator standard hitboxes
  • Fixed an issue where barbed wire completely stops RAM's BU-GI
