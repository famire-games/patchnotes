November 12 Patch Notes: New Character Boris and TalesWeaver Collaboration Update

MapleStory M introduces the new collaboration character 'Boris' and a TalesWeaver collaboration event. The Cash Shop, Beauty Shop, boss entry convenience, and major content UIs have been completely revamped.

Key changes

  • Added new collaboration character 'Boris' and launched Hyper Burning event
  • Revamped Cash Shop, including integration of Crystal and Red Crystal shops
  • Improved Beauty Shop UI and streamlined the purchase process
  • Added instant entry feature for boss content upon meeting combat power prerequisites
  • Significantly revamped overall game UI including shops, dungeons, and party finder
  • Held a job change event allowing the conversion of Boris into a Hero

Bug fixes

  • Fixed an issue where item icons were not visible upon boss reward drops
  • Fixed a skill information button display error for the Epic Dungeon High Mountain quest in PC environments
  • Fixed an issue where Kinesis 'Ever Psychic' finishing blow was not applied to V Matrix enhancement effects
  • Fixed an issue where damage penalty effects were not applied to Ascent skills in some content
