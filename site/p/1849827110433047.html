Update 2.61.0.33 Patch Notes

War Thunder Update 2.61.0.33 fixes a WEP engine thrust bug for Hornet aircraft and updates convoy SAMs at Battle Ratings 13.3 and above. It also adds a shader compilation progress indicator to the hangar and resolves several graphics and system bugs.

Key changes

  • Fixed Hornet aircraft engine thrust decrease bug during WEP
  • Changed convoy SAMs at BR 13.3 and above (Pantsir-S1 to 2S6 Tunguska, ItO 90M to FlaRakRad)
  • Limited FlaRakRad firing range to 10 km, matching the 2S6
  • Added a shader compilation progress indicator to the hangar
  • Fixed AMD GPU driver warning and automatic graphics lowering bug
  • Fixed Linux Wayland window focus bug

Nerfs

  • FlaRakRad firing range limited to 10 km

Bug fixes

  • Fixed engine thrust decrease bug during WEP on all Hornet variants
  • Fixed bug causing clouds to have slightly different shapes on different GPUs
  • Fixed old AMD GPU driver notification and forced graphics downgrade bug
  • Fixed Linux Wayland windowing system focus return bug
