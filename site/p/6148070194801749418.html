Stardew Valley Update 1.6.14

Stardew Valley patch 1.6.14 has been released. Various fixes have been made, including new spouse interactions, preventing the loss of fish when fainting during fishing, and resolving animal produce quality bugs.

Key changes

  • Introduced additional reactions when interacting with a spouse without dialogue
  • Changed mechanics so players no longer lose fish if they faint while fishing or holding a fish
  • Fixed an issue where animal produce was always harvested with 0 quality
  • Improved sound effect playback efficiency
  • Improved menu stability when resizing windows while opening geodes

Buffs

  • Players no longer lose the fish they are holding or catching in a pond when fainting

Bug fixes

  • Fixed an issue where animal produce was always harvested with 0 quality
  • Fixed an issue where spouses would warp to coordinates (0,0) for the farmer
  • Fixed chimney duplication issues when creating new saves on version 1.6.9+
  • Fixed a crash related to homeless farmhands lingering in demolished cabins
  • Fixed an issue where roommates required 2 house upgrades unlike marriage candidates
