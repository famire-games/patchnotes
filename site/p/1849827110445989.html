Escape from Tarkov Patch 1.3.5.0

The Halloween event has ended and the game has upgraded to Unity 6, bringing major performance, loading, and server optimizations. RenderStack has been introduced to improve graphics and rendering performance, along with Handbook category updates and numerous bug fixes.

Key changes

  • Ended the in-game Halloween event and reverted Scav behavior
  • Upgraded the project to the latest version of Unity 6
  • Introduced RenderStack for unified graphics systems and visual effects
  • Reworked raid connection architecture and game server optimization
  • Reworked raid reconnection system to allow faster reconnects without reloading
  • Added separate categories in the Handbook for keys, headwear, armor plates, and more

Bug fixes

  • Fixed issue causing selected character movement speed to reset after packet loss
  • Fixed bots stopping shooting for no apparent reason
  • Fixed PMC bot gear having a Found in Raid mark in PvE Zone
  • Fixed task rewards being granted multiple times on disconnect in local PvE raids
  • Fixed incorrect killer nickname display on Terminal after taking damage on Shoreline
