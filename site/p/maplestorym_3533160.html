8/27 Patch Notes: New Boss Kaling and System Overhaul

MapleStory M has added the new boss Kaling (Normal, Hard), along with new Constella Core skills and expanded maximum levels for link skills. Additionally, daily quests have ended and daily symbol tasks have been newly introduced, alongside major improvements to boss balance and convenience features.

Key changes

  • Added new boss Kaling (Normal, Hard)
  • Expanded link skills to level 3 and added auto-learn feature
  • Ended existing daily quests and newly introduced 'Daily Symbol Tasks'
  • Added new Constella Core skills
  • Improved scheduler task sweeping and registration features
  • Overhauled character balance and usability for Cadena and others

Buffs

  • Ren 'Plum Blossom Sword Technique: Myohwa' buff change allows automatic pet buff registration
  • Phantom 'Steal Skill - Buff Skill' relaxed conditions for registering buff presets
  • Cadena Chain Arts: Takedown multi-hit phase 3 triggered instantly

Bug fixes

  • Fixed an issue where only one difficulty not sharing entry counts among identical bosses in the scheduler was saved
