July 24th MapleStory Worlds Update

The MapleStory Worlds update went live on July 24th. Additions include group profile badges, a revamped Nexon OTP system with trusted device settings, and improved PC bang connection reward notices.

Key changes

  • Added Group Leader badge to group profile pages
  • Improved creator group application and approval/rejection functions
  • Updated Nexon OTP design and added mobile trusted device settings
  • Improved remaining time and unclaimed reward notifications for PC bang connection rewards
  • Displayed accumulated playtime in 1-hour increments upon entering a world
  • Changed the condition for determining world playability to be based on the access region

Bug fixes

  • Fixed an issue where files could not be attached when using 'Contact Creator' on mobile (Android) devices
  • Fixed an issue where search results changed every time a tab or category was switched after searching in the Avatar Shop
