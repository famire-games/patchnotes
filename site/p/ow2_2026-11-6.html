Overwatch Patch Notes - November 6, 2026

This hotfix increases Wrecking Ball's grapple release speed cap, and fixes issues related to previous Competitive Drive signatures, heroes, and the Stadium mode. Replay codes generated from the November 4 patch remain usable.

Key changes

  • Increased Wrecking Ball's base speed cap by 15% when releasing grapple
  • Changed allied speed boosts to affect Wrecking Ball's grapple release speed cap
  • Fixed an issue where previous Competitive Drive signatures could not be unequipped
  • Fixed an issue where pilot D.Mon respawned without ultimate charge (previous update completed)
  • Fixed Stadium scoreboard and related screens not displaying

Buffs

  • Wrecking Ball: Increased base speed cap by 15% while releasing grapple anchor
  • Wrecking Ball: Changed allied speed boosts to increase base speed cap upon releasing grapple anchor

Bug fixes

  • Fixed an issue where players who did not reach Competitive Drive checkpoint 4 could not unequip signatures
  • Fixed an issue where pilot D.Mon respawned without ultimate charge, preventing immediate meka entry
  • Fixed an issue where the Stadium mode scoreboard and related screens were not displayed
