Valorant Patch Notes 13.06

Valorant Patch 13.06 introduces a major overhaul featuring a new home screen and lobby, Agent Mastery system, and the limited-time mode 'Gauntlet: System Error'. Additionally, entering the Practice Range while in queue, Performance Scores, and the new rifle 'Warden' have been added.

Key changes

  • Integrated home screen and lobby into a single hub
  • Added the ability to enter the Practice Range while in queue
  • Introduced 'Performance Score' replacing Average Combat Score (ACS), along with 'Accolades' and 'Rank History'
  • Released new 2v2 limited-time mode 'Gauntlet: System Error'
  • Introduced the 'Agent Mastery' system to showcase dedication to specific agents
  • Added the new long-range automatic rifle 'Warden' priced at 2,900 Creds

Bug fixes

  • Fixed a bug where an agent's ultimate voice line would cut off when using another skill immediately after their ultimate
  • Fixed a bug where agents with control skills were not blinded if hit by an enemy flash right as their skill ended
  • Fixed a bug where Cypher's trap would appear active if he was killed or suppressed at the exact moment of reactivating it
  • Fixed a bug that allowed players to peek rapidly and repeatedly while equipped with the Fleks
