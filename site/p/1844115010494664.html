Patch 1.0.15 Release

A patch addressing overlapping terrain and performance degradation issues has been released. It includes changes to certain items and spawns, and platform-specific rollouts may take a few days.

Key changes

  • Fixed overlapping terrain and performance drop issues
  • Increased drop rate for Deep North armor molds
  • Increased spawn rate and regions for Writhan
  • Fixed item issues affected by developer commands

Buffs

  • Increased drop rate for Deep North armor molds (both Jotun Warrior types now drop medium/heavy armor molds)
  • Increased spawn rate and regions for Writhan

Bug fixes

  • Fixed a terrain overlapping issue that could cause performance degradation
  • Fixed an issue where items on characters with developer bypass commands enabled were incorrectly flagged as cheat items, and made items stackable
