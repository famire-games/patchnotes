Version 4.5 "Gambit Thrown to Fate" Update Notice

Honkai: Star Rail Version 4.5 "Gambit Thrown to Fate" is now live, introducing new Trailblaze Missions, new characters Robin (Summeret) & Aventurine (Wave), along with new events, maps, Light Cones, combat and system optimizations, and bug fixes.

Key changes

  • Added new Trailblaze Mission "Astropolis" - "Gambit Thrown to Fate" and Epilogue
  • Added new 5-star characters Robin (Summeret) (Remembrance/Wind) and Aventurine (Wave) (Enigma/Quantum)
  • Added new Light Cones, cosmetics, and new maps (such as Astropolis Central Zone)
  • Added new event "Limit Break: Sprint Grand Prix" and check-in event "Gift of the Galaxy"
  • Added the [Dialogue Acceleration] feature to increase story dialogue speed
  • Updated the 'Gluttony' erosion system and high-difficulty challenge content "Anomaly Arbitration"

Bug fixes

  • Fixed an issue with Himeko (Nova)'s modeling and visual effects after casting her Technique
  • Fixed an issue where some characters could not attack enemies after using Gilgamesh's Technique
  • Fixed an issue where Jingliu could not enter the [Spectral Transmigration] state while enhanced
  • Fixed multiple combination and numerical calculation errors in content such as Currency Wars
  • Fixed text description and voice subtitle errors for some characters
