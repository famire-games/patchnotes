Garry's Mod April 2026 Update

Black Mesa and Military Conflict: Vietnam can now be mounted, and the Combine APC is introduced as a driveable built-in vehicle. The update also delivers major HUD and 4K improvements, faster server networking, and several bug fixes alongside two hotfixes.

Key changes

  • Added mounting support for Black Mesa and Military Conflict: Vietnam
  • Combine APC added as a built-in drivable vehicle in the spawnmenu
  • HUD improvements including weapon selector scrolling and better 4K scaling
  • Network protocol overhaul to speed up server join times and reduce bandwidth usage
  • Switched internal game systems to double precision time for server longevity
  • Includes hotfixes for prop lighting bugs, physics stability, and Linux crashes

Bug fixes

  • Fixed props and ragdolls turning pitch black when resting on the ground
  • Fixed APC gun effects not working for drivers in multiplayer
  • Fixed crashes when spawning ragdolls inside teleport triggers
  • Fixed crashes when using the physics gun or gravity gun on 32-bit Linux clients
  • Fixed Faceposer re-selection corrupting flex values on ragdolls
