Counter-Strike 2 Update

In this Counter-Strike 2 update, various features and classes related to map scripting have been added and improved. In particular, scripting functions related to instances, consoles, game rules, and hostages have been largely added and overhauled. Additionally, various bug fixes along with improved logging and auto-complete features were included.

Key changes

  • Added Instance.Precache and related state check methods to map scripting
  • Added hostage-related script methods and events
  • Added new top-level export 'Console' and provided related Convar methods
  • Added new top-level export 'GameRules' and migrated related functions
  • Added support for displaying radar_element on the radar in all game modes
  • Added JS call stack and invalid argument value details to log warnings

Bug fixes

  • Fixed a crash that occurred when using GameRules.AddTeamMoney(CSTeamMoneyReason.NONE)
  • Fixed an issue where CSTeamMoneyReason enum values did not match point_script.d.ts
  • Fixed an issue where CSWeaponAttackType enum values did not match point_script.d.ts
  • Fixed an issue where CSRadarPoint.IsVisibleToTeam returned a number instead of a boolean
  • Fixed an issue where CSObservablePoint.IsObservableForTeam returned a number instead of a boolean
