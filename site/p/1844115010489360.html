September 2026 Update

The September 2026 Update for Garry's Mod is now live, introducing 64-bit binaries for Windows, spawnmenu and player model selector overhauls, and various fixes.

Key changes

  • Added 64-bit binaries for the Windows game client, dedicated servers, and developer tools
  • Added Hacked Manhacks NPC and made Dropship NPC take damage in Sandbox
  • Added subcategories to spawnmenu content tabs
  • Overhauled player model selector menu with categories and improved rendering
  • Added support for mounting standalone Insurgency (2014)
  • Released September 17 hotfix for crashes and Linux server issues

Bug fixes

  • Re-enabled ability to override suit/health charger entities & combine mines with Lua entities
  • Added solution steps to 'Failed to init Steamworks' crash dialog
  • Fixed certain addons with weird file names refusing to be mounted on Linux dedicated servers
  • Added fallbacks in panel code to prevent Lua errors from community addons
  • Fixed crash on start up on native 32-bit Linux client
