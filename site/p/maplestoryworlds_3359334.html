MapleStory Worlds · January 28, 2026

1/29 (Thu) Update Patch Notes

A MapleStory Worlds update took place on January 29. Changes include a revised client version numbering format, expansion of profile codes to 6 digits, lobby UI improvements, and the addition of Japanese auto-translation. Various bugs were also fixed.

Key changes

  • Changed regular client update version numbering format (based on Year.Month)
  • Added notification feature when obtaining free World Coins
  • Expanded profile codes from 5 digits to 6 digits
  • Improved lobby screen to display up to 10 worlds
  • Added 'Japanese' to supported auto-translation languages

Bug fixes

  • Fixed an issue where client resolution was intermittently set incorrectly upon launch
  • Fixed an issue where logging out occasionally failed when changing languages on iOS
  • Fixed an issue where category tab navigation buttons in the Avatar Shop did not operate properly
  • Fixed a network error occurring when including '#' during world searches
  • Fixed an invitation code input error in the friend invitation event
