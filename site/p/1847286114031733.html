October 22 Update Details

This update features a seamless maintenance that brings Outbreak mode balance adjustments, character skill and trait balance patches, Halloween-themed maps, and new events. It also includes the Hermes draw pool, various convenience improvements, and bug fixes.

Key changes

  • Outbreak mode cards and trait balance adjustments
  • Character skill and network balance adjustments for Audrey, Aika, Mara, Galatea, etc.
  • Applied Halloween map themes for Fear Town and Glass Cave
  • Hosted String Song Gift, Outbreak Supply Tier 3, and Final Sprint events
  • Opened Hermes 'Sweet Candlelight' and 'Orbit Resonance' limited draws
  • Added kill cam direction settings and ended Vietnamese language support

Buffs

  • Outbreak: [Shield Bash] Maximum damage cap increased
  • Outbreak: [Sturdy Guard] Temporary shield included in damage calculation
  • Aika: Added new passive skill effect (movement speed increases while holding heat)
  • Galatea: Active skill clone base duration increased (7s -> 10s)
  • Galatea: Clone creation scan radius increased (20m -> 25m)
  • Fragrance: Real-time display of team members affected by active and ultimate skills

Nerfs

  • Outbreak: [Card Steal] Cards can now only steal 1-star basic cards
  • Outbreak: [Armor Forger] Armor cap increase amount reduced by half
  • Audrey: 2nd Awakening Auto Turret damage adjusted (10 -> 8 per shot)
  • Ming: 3rd Awakening movement charge time increased (18s -> 20s)
  • Mara: Active skill HP adjusted (125 -> 110)
  • Celestia: 2nd Awakening Flash front duration decreased and rear duration decreased
  • Greatsword dash attack damage adjusted (60 -> 56) and recovery time slightly increased
  • Smoke grenade duration adjusted (9s -> 8s)

Bug fixes

  • Fixed an issue where expired legendary weapon skin trial cards could continue to be used
  • Fixed an issue where characters showed no changes after using dice in Outbreak mode
