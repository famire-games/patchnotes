Mabinogi Mobile · September 30, 2026

10/1 (Thu) Update Notes

Dunbarton Creon pop-up store event quests and a new side game 'Color Rush Blitz' have been added. Archery-class skills have been buffed, NEXON NOW probability information has been updated, and various bug fixes and component retrieval measures have been implemented.

Key changes

  • Added Dunbarton Creon pop-up store-related event quests
  • Added new side game 'Color Rush Blitz' (provides rankings by server, friends, and guild)
  • Added #Multi-Hit tag when equipping Accessory Rune to Archery class 'Heart Seeker' skill
  • Added actual probabilities to the NEXON NOW page and updated probability information
  • Added new events and items such as National Foundation Day On-Time and Creon pop-up store
  • Completed retrieval measures for improperly acquired coupon rewards and additional package components

Buffs

  • Added #Multi-Hit tag when applying 'Accessory Rune: Ultrasound' to the Archery class 'Heart Seeker' skill
  • Increased damage of Archery class 'Death Stinger', 'Deadly Shot', and 'Dragon Bane' skills by 20%

Bug fixes

  • Fixed incorrect end date display for the 'Great Operation to Befriend Sheep!' event quest within the [Quest+] list on the upper right of the main screen
  • Fixed an issue where pausing and exiting was impossible during the 'Special Egg' side quest
  • Fixed an issue where guild information changes intermittently failed in [Edit Guild]
  • Fixed an issue where the same character could receive coupon gifts multiple times
