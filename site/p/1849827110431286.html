26SP6 Season and New Event Update

The Strinova 26SP6 'String Sea Starsong' season begins, bringing various season rewards, new events, and shop items. In addition, bugs related to certain characters like Nora, Audrey, and Chiyo as well as game modes have been fixed.

Key changes

  • Official launch of 26SP6 season 'String Sea Starsong' and season rewards provided
  • Season check-in, season event shop, and baguette discount event held
  • 'Cappuny's Delicious Day' new event and quests opened
  • Orbital Resonance 'Honeyberry Milkshake' and 'Dawn's Bloom' opened
  • Cat Adoption Guide event and beach vacation themed costumes return
  • Fixed bugs and mode errors related to Nora, Audrey, and Chiyo

Bug fixes

  • Fixed an issue in Outbreak mode where Nora's Q skill preview state would freeze
  • Fixed a model error that occurred when Nora performed an aerial jump
  • Fixed an issue where Audrey could not be placed properly on certain terrains and Awakening 2 was placed on abnormal objects
  • Fixed an issue in Demolition mode where the first primary weapon switch could fail during the faction switch phase
  • Fixed an issue in Firing Range mode where Chiyo's weapon damage was abnormal
