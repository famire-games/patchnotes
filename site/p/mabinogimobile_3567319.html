Mabinogi Mobile · October 21, 2026

October 22 (Thu) Update Notes

The October 22 update for Mabinogi Mobile introduces the Halloween-season side game 'Candy Match Survival'. Additionally, NEXON NOW probability info has been improved, and various bugs such as NPC dialogue and graphic errors have been resolved.

Key changes

  • New side game 'Candy Match Survival' added
  • Server/friend/guild ranking system introduced based on 'Candy Match Survival' high scores
  • Excluded ended items and content probability information from NEXON NOW
  • Updated NPC Halloween cat dialogue
  • Fixed other bugs including eye graphic errors for characters under 14 years old

Bug fixes

  • Fixed an issue where unavailable shops were exposed in 'How to Obtain'
  • Fixed an issue where the [Move to Elnid Island] button was exposed when talking to NPC 'Amy'
  • Fixed an issue where eye graphics disappeared when characters under 14 years old with 'Gentle Eyes' applied wore certain patches
