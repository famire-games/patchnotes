Version 3.2 'Their Own Secret History' Update

Zenless Zone Zero Version 3.2 update introduces new S-Rank Agents Claret and Roxy, a new main story, areas, and various events. A total of 600 Polychromes will be distributed as server update and bug fix compensation.

Key changes

  • Added new S-Rank Agents Claret (Electric, Armor-bearer) and Roxy (Wind, Stun)
  • Added Main Story Season 3 Chapter 3 'Their Own Secret History'
  • Added new areas including 'Roscalifer - Vairium District'
  • Added new limited-time costumes for Nankong, Aria, and Sunna
  • Added beginner's guide selective limited S-Rank Agent and W-Engine rewards
  • Hosted various new events including the attendance event 'All-New Program'
