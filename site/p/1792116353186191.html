Black Myth: Wukong Patch 1.0.14.17737

Patch 1.0.14.17737 for Black Myth: Wukong has been released. This update includes bug fixes for boss fights and level progression, improvements to the protagonist's skill combos, and the addition of the experimental Neural Super Sampling Resolver (NXSR).

Key changes

  • The patch size is approximately 1.9 GB, and requires about 4.5 GB of temporary storage space.
  • A new experimental super-resolution sampling method, NXSR, has been added to the graphics settings.
  • Fixed bugs related to bosses such as Yellowbrow and Erlang.
  • Adjusted the protagonist's skill combos and the activation conditions for the soak 'Wintry Haze'.
  • Fixed interface errors related to the Journey Map and Challenge Mode.
  • Fixed an issue where purchasing items in bulk resulted in incorrect quantities for certain curios.

Bug fixes

  • Fixed an issue in Challenge Mode where the 'Keeper of Relics' Yellowbrow could permanently remain invisible under certain conditions
  • Fixed an issue in Challenge Mode where the Guard Gauge of Erlang from 'Brothers of Mount Mei' would recover abnormally
  • Fixed an issue where the door in 'Forest of Wolves' in Flaming Mountains would not open upon re-entry
  • Fixed an issue where the protagonist's skills would not chain correctly
  • Fixed an issue where areas around 'Emerald Hall' on the Journey Map could not be unlocked
