Baldur's Gate 3 Hotfix #33 Released

This hotfix addresses game crashes, radial menu lag and portrait issues when using a controller. It also resolves errors that occurred when publishing large mods, along with various gameplay and UI bug fixes.

Key changes

  • Resolved the 'A task was cancelled' error when publishing large mods
  • Fixed lag and portrait issues when using controller radial menus
  • Fixed various crashes and performance drops
  • Fixed progression-blocking bugs in split-screen and multiplayer
  • Corrected spoiler dialogue lines in the Underdark
  • Adjusted balance for Crawling Claw's Necrotic Claw

Nerfs

  • Crawling Claw's Necrotic Claw now only deals additional damage on a successful hit rather than applying extra damage on a miss.

Bug fixes

  • Fixed a potential crash that occurred when using 'Set Slot' in the radial menu
  • Fixed potential crashes related to combat and trade UIs
  • Fixed a crash that occurred after failing a specific Arcana check in Moonrise Towers
  • Fixed freezing issues on Xbox when resuming from a suspended state or leveling up
  • Fixed a bug where save games could not be loaded due to corrupted data
