V72 Bug Fix Patch

This patch fixes various bugs related to the V70 added content. It resolves spawn errors for items like the clock, candy scrap, and gift boxes, as well as enemy pathing and interaction issues inside the mansion.

Key changes

  • Fixed an issue where clocks and candy scrap failed to spawn
  • Fixed an issue where enemies could not move over beds and garage cars inside the mansion
  • Fixed enemy interactions with the bathroom shower doors inside the mansion
  • Fixed an issue where gift boxes contained identical items based on the planet instead of random items
  • Fixed a bug where birds instantly killed enemies instead of dealing rapid damage

Bug fixes

  • Fixed clock and candy scrap spawn bugs
  • Fixed enemy movement paths and shower door interactions inside the mansion
  • Fixed gift box random item spawn bug
  • Fixed bird instant-kill enemy bug
  • Fixed body part generation errors and memory leaks upon death from a Giant Sapsucker
