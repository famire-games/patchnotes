Dota 2 Gameplay Patch 7.41f

Dota 2 patch 7.41f has been released, addressing various in-game bugs and interaction errors. Issues related to terrain getting stuck around the top Roshan pit and problems with several heroes' skills and items have been resolved.

Key changes

  • Fixed an issue where heroes could hide in terrain near the top Roshan pit
  • Fixed a bug related to sale displays for unsellable items
  • Fixed an issue where cooldowns were not applied when dismantling Tranquil Boots
  • Fixed hero skill errors for Bane, Bounty Hunter, Elder Titan, and others
  • Fixed Spirit Breaker's Planar Pocket interaction error

Bug fixes

  • Fixed locations where heroes could hide in the top Roshan pit terrain
  • Fixed an issue where unsellable items could be displayed as sellable during the initial sell period
  • Fixed an issue where cooldowns were not applied when dismantling Tranquil Boots in the stash
  • Fixed an issue where Bane's Nightmare removed vision from debuff-immune targets
  • Fixed an issue where Bounty Hunter's 'Big Game' talent did not grant bonus gold
