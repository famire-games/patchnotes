Stardew Valley Patch 1.6.15 Released

Stardew Valley patch 1.6.15 has been released. Various quality-of-life improvements and bug fixes have been implemented, including buffs to Legendary Fish Ponds and the addition of a bundle button in the fridge UI.

Key changes

  • Increased productivity for Legendary Fish Ponds
  • Added a Junimo Bundle button to the refrigerator and mini-fridge UI
  • Optimized game performance
  • Removed unnecessary profanity filters on certain platforms
  • Fixed an issue preventing Japanese players from accessing Krobus's shop on Fridays
  • Fixed multiple multiplayer and mod-related bugs

Buffs

  • Legendary Fish Ponds now produce roe much more frequently, increasing their average daily value

Bug fixes

  • Fixed an issue where Krobus's shop could not be accessed on Fridays
  • Fixed a rare data corruption issue where data could be incorrectly copied when viewing the loading screen before creating a new farm
  • Fixed a crash that occurred when collecting from empty fish traps
  • Fixed a crash that occurred when farm animals existed in multiple locations simultaneously
  • Fixed a crash that occurred when a farmhand passed out while changing locations
