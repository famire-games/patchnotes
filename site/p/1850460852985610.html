13.2a Hotfix

The Eternal Return 13.2a hotfix has been released. You can update by restarting the game client. This hotfix primarily addresses bugs such as UI and tooltip errors.

Key changes

  • Meisa's subject records now display correctly
  • Meisa release collection's Oopsie icon and emoticon display correctly
  • Collection reward popups now display the correct collection name
  • Holy Water tooltip correctly displays defense increase values

Bug fixes

  • Fixed an issue where Meisa's subject records were not displaying properly
  • Fixed Meisa release collection's Oopsie icon and emoticon images rendering normally
  • Fixed unboxing collection reward popups displaying the correct collection name
  • Fixed Holy Water tooltip correctly displaying the actual defense increase values applied
