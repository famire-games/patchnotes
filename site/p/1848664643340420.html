Marvel Rivals Patch Notes - November 5, 2026

A Marvel Rivals patch will be deployed without server downtime on November 5, 2026, at 9:00 AM UTC. New store items have been added, alongside bug fixes for Moon Knight and Captain America.

Key changes

  • Patch deployed without server downtime
  • Added new store items including Spider-Man Washed Bundle and Emote Bundle
  • Added The Thing Cosmic Cook Bundle
  • Added visual effects for Spider-Man's Ultimate ability
  • Fixed damage bugs related to Moon Knight's team-up
  • Fixed landing position synchronization issue for Captain America's team-up

Bug fixes

  • Fixed a bug where Moon Knight teamed up with Elsa Bloodstone failed to deal damage to Doctor Strange's barrier and other shields
  • Resolved an issue where Captain America teamed up with Winter Soldier had an offset landing position missing the Spell Field buff
