Black Myth: Wukong Update 1.0.20.22023 Patch Notes

Patch 1.0.20.22023 for Black Myth: Wukong has been released. It includes improvements to the Giant Shigandang boss fight, integration of AMD FSR4 alongside graphics and performance optimizations, and various bug fixes.

Key changes

  • Improved combat experience against the Yaoguai King 'Giant Shigandang'
  • Added AMD FSR4 integration support (requires driver configuration)
  • Significantly improved lighting quality when Global Illumination is set to 'Low'
  • Improved CPU, rendering performance, and memory usage
  • Added Czech language support
  • Improved compatibility mode (prevents startup failures)

Bug fixes

  • Fixed an issue where the Yaoguai Chief 'Double-headed Rat' could become unkillable under certain conditions
  • Fixed an issue where iron balls were not displayed properly during the 'Double-headed Rat' boss fight
  • Fixed an issue where XeSS 2.0 frame generation failed to activate on some displays
  • Fixed a crash that occurred when DLSS 4 frame generation and ray tracing were enabled simultaneously
  • Fixed a rendering bug that caused ghosting and edge flickering with NXSR
