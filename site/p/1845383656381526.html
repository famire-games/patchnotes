The Witcher 3: Wild Hunt Hotfix 5.00c Released

Hotfix 5.00c is now available for the Steam version of The Witcher 3: Wild Hunt. This update resolves save/load issues caused by special characters in file paths, audio bugs, and visual adjustments in Velen.

Key changes

  • Fixed save/load issues when the Documents folder path contained special characters
  • Made various visual adjustments in Velen, including Bloom, vegetation lighting, and Path Tracing
  • Reverted changes causing performance and visual issues with HairWorks for some users
  • Fixed an issue preventing players from launching the Classic (1.32) version

Bug fixes

  • Fixed an issue where the game couldn't be saved or loaded with special characters in the Documents folder path
  • Fixed an issue where voiceover audio became quieter after navigating pause menu tabs
  • Fixed marketing telemetry settings not saving properly
  • Fixed an issue where launching the Classic (1.32) version was not possible
