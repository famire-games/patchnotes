Version 4.0 "Full Moon, A Time Without Gods" Update Notice

The Honkai: Star Rail Version 4.0 "Full Moon, A Time Without Gods" update is underway. New Trailblaze Missions, new characters (Hyoguak, Sparky) and Light Cones are added, along with various events and system convenience optimizations.

Key changes

  • Added new Trailblaze Mission "Ideal Paradise" - "Full Moon, A Time Without Gods" and Adventure Missions
  • Added new 5-Star characters 「Hyoguak (Enigmata/Physical)」, 「Sparky (Enigmata/Fire)」 and new Light Cones
  • Hosted various new events, including "Illusion Gift" where players can select and obtain 1 limited 5-Star character
  • Optimized assignment dispatch format (select up to 4, auto-accumulates every hour, holds up to 30 hours)
  • Added support for previewing ununlocked substats on Relics
  • Optimized trial character additions during party formation

Bug fixes

  • Fixed an issue where certain effects of character Dahlia's combat skill triggered abnormally under specific circumstances
  • Fixed an issue where the target selection for extra attacks in character Feixiao's and enhanced Kafka's talents was abnormal under specific circumstances
  • Fixed an issue where character Fu Xuan's Trace [Liuren Oracle] was abnormally applied multiple times to certain Memory Spirits under specific circumstances
  • Fixed an issue where the achievement "Long Journey to the Night" could not be completed
  • Fixed an issue where some models of the pet "Sarcastic Cat" displayed abnormally
