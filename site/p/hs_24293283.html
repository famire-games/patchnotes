Patch 36.4 Notes

Patch 36.4 introduces the new class set "Azeroth's Most Wanted" and a new Arena season. It also brings the Rulebreaker's Bash event, the World Championship Tavern Brawl, transformative Mythic Hero skins, and various content updates and bug fixes.

Key changes

  • Released the 'Azeroth's Most Wanted' class set for Priest, Rogue, Warlock, and Warrior
  • Started a new Arena season (including Escape from Violet Hold and more)
  • Hosted the Rulebreaker's Bash event with free rewards
  • Held a Tavern Brawl utilizing decks from past World Champions
  • Added the transformative Lich King Kel'Thuzad Mythic Hero skin
  • Fixed various in-game and visual bugs

Bug fixes

  • Fixed an issue where Shadow of Demise drawn by Kingsbane could be played
  • Fixed an issue where Blood of Death drawn and cast twice by Jailer Architect summoned an incorrect number of Unstable Skeletons
  • Fixed an issue where Baron Vashj's attack could be interrupted by Mystical Decoy
  • Fixed an issue where Objection! triggered before Counterfeit Blade
  • Fixed an issue where Violet Punisher failed to properly inherit and transfer keyword effects in certain situations
