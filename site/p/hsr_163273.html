Version 4.1 "Rampage Dedicated to Dawn" Update

Honkai: Star Rail Version 4.1 "Rampage Dedicated to Dawn" has been released. Various content has been added, including new Trailblaze Missions, a new character 'Ashveil' and Light Cones, as well as Divergent Universe updates and events.

Key changes

  • Added new Trailblaze Mission "Ideal Paradise" - "Rampage Dedicated to Dawn"
  • Added new 5-Star character 'Ashveil (The Hunt: Lightning)'
  • Added new 5-Star Light Cones 'Epilogue of Lies' and 'Overflowing Festival of Joy'
  • Added new Divergent Universe assignment 'Paradise Miscellaneous Notes' and hosted new event 'True Spirit Chaos Chronicles'
  • Added a feature to directly save character guide recommended lineups to party formations
  • Fixed numerous bugs related to heroes, enemies, and systems, and optimized Korean voice acting/text

Bug fixes

  • Fixed an abnormal effect with Black Swan's extra ability 'Sign of Candle Shadows'
  • Fixed an issue where Phainon's action order was displayed abnormally after transformation ended
  • Fixed errors related to the effects of the Planar Ornaments 'Land of Dreams Amporeus' and 'Tengoku@Livestreaming'
  • Fixed an issue during certain missions where Firefly's model disappeared and movement became impossible after triggering her technique
  • Fixed an issue where the achievements 'All is Already Decided' and 'I Understand Everything!' could not be completed
