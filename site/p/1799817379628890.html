Baldur's Gate 3 Patch 8 and Hotfix #32

Cross-play functionality between platforms and new level 9 specialized subclasses have been added. Hotfix #32 has also been applied to improve game stability and resolve crashes.

Key changes

  • Added cross-play support across all platforms
  • Added new subclasses for each class (Giant Barbarian, College of Inspiration Bard, Death Domain Cleric, etc.)
  • Introduced Larian account linking and friend adding features
  • Improved multiplayer lobby creation and joining features
  • Provided mod verification windows and mod limitation guides
  • Applied Hotfix #32 to resolve game crashes and performance issues

Bug fixes

  • Fixed toolkit crashes caused by invalid control character inputs
  • Fixed crashes occurring when changing input modes while running multiplayer
  • Fixed split-screen crashes with DLSS enabled on Vulkan
  • Fixed a bug where multiplayer client avatars appeared transparent until moving
  • Fixed a bug where the main menu background turned black after character creation
