v1.0.4 Balance Adjustment and Bug Fix Patch

Palworld v1.0.4 update has been released. Along with new sub-missions, Pal and combat balance adjustments, and fishing system improvements, various bug and performance stability issues have been fixed.

Key changes

  • Added new sub-missions 'Beyond Dimensions' and 'From the Far Side of the Moon'
  • Adjusted summoned Pals and base Pals to prioritize skills expected to deal higher damage
  • Adjusted fishing difficulty and rewards in Sunreach and World Tree regions
  • Changed returned materials from cancelled production facility tasks to go directly into the inventory
  • Changed the default FPS cap to 120 on the PC version
  • Fixed various crash, multiplayer, and server-related bugs

Buffs

  • Materials from cancelled production facility tasks are returned directly to the inventory
  • Improved building cancellations or dismantles so only overweight materials drop in front of the player's feet
  • Fixed the map to reopen when approaching an unlocked tower from an unexplored area
  • Added a name search function to the Palpedia

Nerfs

  • Changed the minimum use distance of 'Power Bomb' to reduce unnatural repetitive backsteps
  • Changed players and Pals so they no longer catch fire upon touching player-placed campfires

Bug fixes

  • Fixed an issue where controls became unresponsive after returning to the title screen due to a connection error during loading
  • Fixed an issue where recalled Pals could not be re-summoned immediately after being summoned
  • Fixed an issue where participating players incorrectly joined the host's guild in Co-op mode
  • Fixed an issue where Killamari Primo's partner skill Lv. 2 and Lv. 3 effects were reversed under certain conditions
  • Fixed an issue where sale amounts were calculated incorrectly when selling multiple items at a shop
