June Team Update Guide

Ahead of the July update, changes to event schedules, August server merge plans, Solo Mode expansion, and quality-of-life improvements have been announced. Certain events like the Kazeros Challenge Express will end early on August 19 to facilitate server merges. Various convenience improvements, such as automatic Ark Grid and card set equipping, are scheduled for July.

Key changes

  • Event end dates, such as the Kazeros Challenge Express, moved early to August 19
  • Intra-region server merges scheduled for August
  • Addition of Solo Mode (Act 4, Denuoma) and matching modes in the July update
  • Added automatic Ark Grid Astrogem equipping feature
  • Added automatic card set equipping feature tailored to raid attributes
  • Introduced Ark Grid recommended skill system

Nerfs

  • Early shortening of end dates for Kazeros Challenge Express, Twilight Road & Shop, and Mokoko Bootcamp
