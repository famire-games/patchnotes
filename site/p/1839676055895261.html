3.26.3.7 and 3.26.3.8 Patch Notes

Mitigated the anti-abuse measures applied in patch 3.26.3.5 and restored most content. Fixed issues with boombox URL handling, asynchronous loading weather prefabs, and several other bugs.

Key changes

  • Relaxed anti-abuse measures from patch 3.26.3.5 and restored content
  • Modified boombox links to open the original URL rather than the parsed URL
  • Fixed missing static Unity event checks for asynchronously loaded lightning and custom weather prefabs
  • Fixed inconsistent ordering exceptions when server prefabs contained multiple components of a specific type
  • Fixed compatibility issues between classic canned beans skins and the Wild Harvest eating animation
  • Released the 3.26.3.8 minor patch to resolve Unity Events validation issues

Bug fixes
