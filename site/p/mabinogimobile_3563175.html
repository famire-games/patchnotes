10/15 Update Notes Summary

The October 15 update for Mabinogi Mobile adds new Halloween events and quests, new difficulties for Rundal Abyss, a guild integration system, and Pet Expeditions. In addition, certain skills and rune effects for Mage and Rogue classes have been buffed, alongside various quality-of-life improvements and bug fixes.

Key changes

  • Added new event quests, showroom, photo booth, and side game 'Candy Match Survival'
  • Added 'Very Hard 2' and 'Hell 4' difficulties for Rundal Abyss
  • Added 'Guild Integration' system allowing members to move to other guilds
  • Added 'Pet Expedition' feature to feed pets and acquire loot
  • Started Nightmare Drill Season 2 and adjusted demonic resistance and pressure
  • Added a chance to remove equipment curses when interacting with a campfire

Buffs

  • Increased charge-stage damage by up to 16.7% when applying Mage class 'Plasma Cloak' skill + accessory rune 'Storm'
  • Increased additional hit probability for Mage class 'Charge Electricity' from 10% to 15%
  • Increased additional attack activation probability for Rogue class 'Burst Punch' + accessory rune 'Ascension'
  • Added an effect to Rogue class 'Deadly Impact' increasing critical damage proportional to strike enhancement stats by up to 10%

Nerfs

  • Reduced HP and attack power following level adjustments for Airel Raid Very Hard difficulty

Bug fixes

  • Fixed a typo in Armor Rune: Twilight Breath description from 'Periodic Damage: Divine' to 'Periodic Damage: Judgment'
  • Fixed an issue where stone pillars did not summon when a Rogue class played Kabrak Intro/Hard solo
  • Fixed an issue where some skill cooldowns were not reset when acquiring the Awakening buff after breaking Black Succubus in White Succubus Hard/Very Hard
  • Fixed an issue where hit combos did not stack properly when Rogue class 'Thrust Kick' + 'Advance' rune was applied
  • Fixed an issue where an instruction message was displayed even without loot in an unselected mission state upon dungeon clear
