Eighth Moon Version Update Guide

The 'Eighth Moon' version of Genshin Impact is live, opening up the new Nod-krai regions 'Dunanna Hollow' and 'Frostmoon'. New 5-star character Sandrone, weapons, quests, and system content have been added alongside various bug fixes.

Key changes

  • New regions 'Dunanna Hollow' and 'Frostmoon' opened
  • New 5-star character 'Reflected Formula - Sandrone (Cryo)' released
  • New Claymore 'Key of Transcendence' added
  • New system content 'Witch's Revelation' and new elemental reaction 'Star Superconduct' added
  • Imaginary Theater and Spiral Abyss updates
  • Genius Invokation TCG card updates and balance adjustments

Buffs

  • Reduced elemental dice cost when using Genius Invokation TCG support card 'Elemental Conversion: Superconduct Blessing'
  • Reduced elemental dice cost for Genius Invokation TCG character card Tighnari's talent card 'Keen Sight'

Nerfs

  • Reduced piercing damage dealt by Genius Invokation TCG 'Superconduct Blessing - Blitz'

Bug fixes

  • Fixed an issue where certain objectives could not be completed during Archon Quests and Story Quests
  • Fixed an issue where the enemy 'Sentinel - Corrupted' would not fall down when its elemental shields were destroyed
  • Fixed visual effect and modeling display errors for certain characters
  • Fixed an issue where HP did not increase when the effect of Genius Invokation TCG support card 'Chenyu Vale' was applied
  • Fixed an issue where game crashes occurred when launching the game on iOS Developer Beta OS
