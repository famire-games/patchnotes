Mabinogi Mobile · November 18, 2026

11/19 Update Notes

The 'Very Hard' difficulty for the Cabrac Raid has been added, along with related achievements and loot. Minimum specs for iOS devices have been changed, and various bug fixes and convenience improvements have been applied. New items and events have been added.

Key changes

  • Added 'Very Hard' difficulty for Cabrac Raid
  • Added new Cabrac Raid achievements and loot
  • Added 'Cabrac Statue' decoration with no trade count limit
  • Changed minimum iOS device requirement for Mabinogi Mobile to iOS 17
  • Added new item 'Warm Mission Cash-back Package'
  • Added new events (Red Bean vs. Choux Cream, etc.)

Bug fixes

  • Fixed an issue where purchasing certain items displayed 6 general MCash items instead of the MCash items matching the price
  • Fixed an issue where the ended 'Challenge, The Relived Tower of Phantoms' event was displayed
  • Fixed an issue where using 'Action: Maple Leaf Observation' caused actual in-game actions to appear differently than intended
  • Fixed an issue where additional loot could be acquired by clearing the raid before the weekly loot settlement
  • Fixed an issue where the Little Dragon Gecko legend pet effect was not displayed and graphic errors occurred when wearing certain coats
