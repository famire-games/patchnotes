March 12 Update Notice

A new map 'Abyssal Frontier' has been added, along with the Outbreak mode and balance adjustments for several characters. Additionally, Season 26SP2 'Hall of Pioneers' has begun, accompanied by various events and shop item refreshes.

Key changes

  • Added new Outbreak mode map 'Abyssal Frontier'
  • Launched Season 26SP2 'Hall of Pioneers' and related events
  • Adjusted character skills and balance for Kanami, Ming, Reyichi, Ciel, and others
  • Adjusted damage for weapons and String Energy Network growth options
  • Added new Map Workshop and improved features
  • Implemented various bug fixes and optimizations

Buffs

  • Ming: Buffed active, sub, and ultimate skill damage as well as defense absorption rate
  • Reyichi: Reduced active skill cooldown and buffed base damage
  • Ciel: Buffed active skill shield amount and healing effects
  • War Scythe: Increased attack speed by 5%
  • Ignis: Increased damage scaling against Stringified enemies

Nerfs

  • Kanami: Increased ultimate point requirement (6500 -> 7000)
  • Leona: Reduced primary weapon calibrator fire rate and base magazine size
  • Nerfed damage of String Energy Network growth options for certain characters

Bug fixes

  • Fixed a sound output error for H-Petalbound Amber Case
  • Fixed a modeling display error for Michelle's 'Battle Scar' skin
  • Fixed an issue where Kanami's ultimate blocked movement through wind currents on the Lava Factory map
  • Fixed a getting-stuck issue after Stringification in specific areas of the Taibe Oasis map
  • Other text display error fixes
