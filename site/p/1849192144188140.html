Kinetic Update - Beta - Hotfix 1

The first hotfix for the Railroads Online Kinetic Update Beta is now available. This update brings an auto fireman feature, developer guidance on tracks and industries, and numerous bug fixes.

Key changes

  • Added an auto fireman feature to automatically move fuel from tenders to fireboxes (except 'Realistic' setting)
  • Removed some docks on Pine Valley spawn to allow continuous track placement
  • Increased the speed at which end of track devices trigger a derail to 10mph or less
  • Provided developer notes regarding crossovers, track connections, and floating industries

Bug fixes

  • Fixed an issue where clients could see floating values above cars and tenders
  • Fixed a fatal error when loading the skeleton cars
  • Fixed an issue where roundhouses would derail trains
  • Fixed an issue where players could not delete the truss bridge
  • Fixed an issue where clients couldn't uncouple cars if the host was not near
