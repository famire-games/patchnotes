VALORANT Patch Notes 13.10

VALORANT Patch 13.10 adds a replay bookmark feature, reduces post-destruction cooldowns for Sentinel abilities, changes the assist system, and updates the 'Gauntlet: System Error' mode along with various bug fixes.

Key changes

  • Added a replay bookmark feature to record crucial moments
  • Reduced post-destruction cooldowns for Cypher, Killjoy, and Vyse abilities (60s -> 45s)
  • Improved target designation accuracy and crosshair display for Sage's Healing Orb
  • Changed rules for damage assists and healing assists
  • 'Gauntlet: System Error' mode now supports up to 5-player queues and adds new skills/ultimates
  • Balance adjustments for various Agent skill upgrades

Buffs

  • Cypher Spycam: Reduced post-destruction cooldown (60s -> 45s)
  • Killjoy Turret: Reduced post-destruction cooldown (60s -> 45s)
  • Vyse Arc Rose: Reduced post-destruction cooldown (60s -> 45s)
  • Stim Beacon (Insta-Stim): Increased duration (2s -> 4s)
  • Prowler (Fat Cat): Increased health

Nerfs

  • Cypher Spycam: Increased retrieval cooldown (15s -> 20s)
  • Blaze (Fast Burn): Increased recharge cooldown for levels 2-3
  • Boom Bot (Overclock): Decreased movement speed and activation duration
  • Stim Beacon (Super Stim): Decreased duration (12s -> 10s)

Bug fixes

  • Fixed a bug where smokes would disappear instantly instead of fading out gradually when reconnecting after disconnecting
  • Fixed a bug where Chamber's Rendezvous would play voice lines to spectators when used outside its range
  • Fixed a bug where Sage could heal allies out of sight using Healing Orb
  • Fixed a bug where Viper's Pit failed to play voice lines upon activation
  • Fixed a bug where Vyse's Steel Garden incorrectly displayed weapon-disable visual effects at the edge of its range
