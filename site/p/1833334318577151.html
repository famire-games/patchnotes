War Robots 12.1 Update Notes

The War Robots 12.1 update is here, bringing the new robot Shoggoth, long-range weapons, drones, a mothership, and the Ultimate Rhino overhaul. Additionally, the Unstable Conduit has been updated along with several bug fixes.

Key changes

  • New robot Shoggoth and weapons Voonith, Urhag, Shantak
  • New Ultimate editions: Rhino, Toxin, Venom
  • New drone Fhtagn and mothership R'lyeh
  • New pilots Baek Taejun and Kai Ruo
  • Unstable Conduit active module update

Bug fixes

  • Fixed missing item icons in Hank's Drifting Shipyard
  • Fixed Lilian Statera's legendary skill not working on Hades
  • Fixed Customization Adept in Ultimate Revenant pilot skill pool
  • Fixed thruster VFX not displaying correctly on Lancelot
  • Fixed Supply Center button incorrectly displaying collecting rewards state
