September Update: Dimensionalist and Gear Progression Improvements

The new class 'Dimensionalist' is added alongside a massive revamp to simplify the gear progression path from Tier 3 to Tier 4. In addition, advanced honing mitigations, growth boost shops, a new Guardian, balance patches for all classes, and various events are applied.

Key changes

  • Released new class 'Dimensionalist'
  • Revamped gear progression path from Tier 3 to Tier 4
  • Applied advanced honing mitigations and added growth boost shop items
  • Added new Guardian 'Guardian's Shade'
  • Applied balance changes for all classes
  • Hosted 4 events including Jump-Up Boost and Mahakala Returns

Buffs

  • Accelerated gear progression speed from Tier 3 to Tier 4 (targeted at new and returning players)
  • Applied advanced honing mitigations
