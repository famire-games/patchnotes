Honkai: Star Rail · November 10, 2026

Version 4.7 "Now, Let the Multiverse Smile"

The Honkai: Star Rail Version 4.7 update "Now, Let the Multiverse Smile" is now live. It introduces new Trailblaze Missions, the new character 'Aeons★Aha', and various events and system improvements.

Key changes

  • Unlocked new Trailblaze Mission "Ideal Paradise" - "Now, Let the Multiverse Smile"
  • Added new ★5 Character "Aeons★Aha (The Joy • Quantum)" and new Light Cone
  • Added Special Eidolon "Karma Eidolon" system (applicable to Acheron, Dan Heng • Imbibitor Lunae, and Jing Yuan)
  • Added character-exclusive effect toggle feature
  • Optimized character growth quick-acquisition features and supported dialogue playback speed for Versions 1.0–3.8
  • Large-scale events and reward distribution (choice between Acheron, Dan Heng • Imbibitor Lunae, and Jing Yuan)

Bug fixes

  • Fixed an abnormal issue with reduced remaining turn counts after Memory Spirits 'Ica' and 'Demiourgos' activate skills
  • Fixed an abnormal issue with the defeat-prevention effect of enemy 'Blood of the Fallen God • Yabuli' during combat
  • Fixed errors in certain Curio/Skill/Buff text and status ailments within Simulated Universe and Currency War contents
  • Fixed interaction errors with specific destructible objects in certain fields and Astropolis
  • Fixed multilingual voice and story dialogue text errors in languages such as Korean and Japanese
