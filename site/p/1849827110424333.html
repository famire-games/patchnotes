Patch 11.01: New Legend Morgwyn & In-Game Tournaments

The 71st Legend Morgwyn has arrived with Gauntlets and Greatsword. Closed beta for the new In-Game Tournament feature is now launching, alongside map pool updates and various bug fixes.

Key changes

  • New 71st Legend 'Morgwyn' added with Gauntlets & Greatsword
  • In-game Tournament feature closed beta begins
  • Map pools updated for Tournament and Standard queues
  • PC/Mac Image Render Tool updated with emote variants and sidekick options
  • Improved level-up dance animation for SpongeBob Squarepants and Patrick Star

Bug fixes

  • Fixed an Image Render Tool bug with incorrect podium animation frames
  • Fixed a bug where the Recovering challenge loaded into a black screen
  • Fixed a bug with flipped Legends appearing in the wrong position on the Match Preview screen
