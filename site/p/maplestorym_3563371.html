10/15 Patch: Artium Region and Ascent Skills Added

The new Grandis region 'Artium' and 'Ascent Skills' for all classes have been added to MapleStory M. Combat power guides and various content UIs have been completely revamped, along with updates to various events and shop items.

Key changes

  • Added new Grandis region 'Artium' and Authenticforce field
  • Added Ascent Skills for all classes and HEXA Matrix skill cores
  • Improved combat power guide and recommended stats guidance for unreflected items
  • Completely revamped UI for Arcane/Authentic symbols and various daily content
  • Hosted large-scale 10th-anniversary events such as 'Protect Aru and Eru's Festival'
  • Fixed and improved skill bugs for some classes including Soul Master and Demon Avenger

Buffs

  • Changed Soul Master to allow movement when using 'Cross the Styx' during the 'Elysion' buff

Bug fixes

  • Fixed a bug showing incorrect ignore defense rates in Shadower's 'Cutdown' skill description
  • Fixed an issue where 'Rift of Boundary' did not trigger when hitting with Cross the Styx during Soul Master's 'Elysion' buff
  • Fixed an issue where Hoyoung's 'Sage: Clone Transformation - Tai Hsu' was not used during auto-battle
  • Fixed an error related to the minimum unit of the passive effect for Demon Avenger's 'Conversion Star Force'
  • Fixed an issue where the attack type for the 'Magic Circuit Full Drive' skill was set to physical
