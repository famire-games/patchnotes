Patch 1.0.17

A minor patch addressing bugs such as object deletion caused by world save file splitting and incorrect shield variants on PlayStation 5. Platform-specific uploads may take a few days, but crossplay will remain functional.

Key changes

  • Fixed a rare bug where objects were deleted when splitting large world save files
  • Fixed invalid item types such as incorrect shield variants in PS5 version 1.0.15
  • Reset invalid styles to default styles so they function properly
  • Updated some placeholder text
  • Restored credits that were hidden in version 1.0.16

Bug fixes

  • Fixed a rare bug where objects were deleted when splitting world save file chunks
  • Fixed abnormal behavior caused by invalid item types
  • Updated some placeholder text
  • Restored hidden credits
