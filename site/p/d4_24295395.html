Diablo IV Patch 3.2 Notes

Diablo IV Version 3.2 update increases the stack limit of Archdemon's Thorns and fixes various progression-blocking bugs and issues. Various quality-of-life improvements were made to stability, performance, and UI.

Key changes

  • Increased Archdemon's Thorns stack limit to 99
  • Fixed bugs preventing season-linked quests and dungeon progression
  • Fixed Horadric Cube affix re-rolling issue
  • Fixed bugs related to Druid and Sorcerer classes
  • Fixed bugs related to runes and equipment
  • Improved stability, performance, and visual elements

Buffs

  • Increased the maximum stack count of Archdemon's Thorns from 1 to 99.

Bug fixes

  • Fixed an issue where Archdemon's Thorns could be used before completing seasonal linked quests
  • Fixed an issue where Tyrrael's spawn location after defeating Baal made it difficult to loot items
  • Fixed an issue where the Sandstone Golem in the Library of the Horadrim would not revive upon dying in combat
  • Fixed an issue where the Blood Bishop of the Forgotten Tower could phase through the fog wall and block combat
  • Fixed an issue where certain affixes would not re-roll using the Horadric Cube
