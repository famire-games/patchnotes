Mabinogi Mobile · November 11, 2026

11/12 (Thu) Update Notes

The November 12 update for Mabinogi Mobile adds 4 new Dunbarton Secret Vigilante-related event quests, 3 new rebirth-selectable appearances, and package hairs. It also fixes Memorial Saga Familiar skill errors, updates NEXON NOW drop rate information, and introduces various graphic and quality-of-life improvements.

Key changes

  • Added 4 new event quests related to the Dunbarton Secret Vigilante
  • Added new selectable appearances for rebirth and 3 new Cash Shop package hairs
  • Fixed skill and description errors for Memorial Saga Familiars such as 'Pledged Yellow Mushroom'
  • Fixed an issue where Memorial Saga Familiars dealt damage to allies
  • Improved NEXON NOW page drop rate information and pet tag acquisition drop rate page naming
  • Fixed graphic errors for other adventurers' collaboration fashion set effects and character appearances

Buffs

  • Added Memorial Saga 'Pledged Yellow Mushroom' Vitality Spore skill effect (increases nearby familiars' and character's attack/movement speed by 20%)

Bug fixes

  • Fixed an issue where Memorial Saga Familiar 'Pledged Yellow Mushroom' skills were not applied and abnormal descriptions were displayed
  • Fixed an issue where 'Pledged Troublemaker Imp' and 'Pledged Black Direwolf' skills dealt damage to allies
  • Corrected 'Exquisite Acceleration Scroll' item description to match actual applied effects
  • Fixed unnatural movement of the Memorial Saga Floor 100 boss
  • Fixed text inversion and transformation graphic errors when equipping Yeomin Feather Uniform Gloves
