Hotfix 760178 Update

Don't Starve Together Hotfix 760178 has been applied. The Pig King now has a chance to give pumpkin bombs along with candy, leaf piles drop snacks more frequently, and various bugs have been fixed.

Key changes

  • Added a chance for the Pig King to drop pumpkin bombs when giving candy
  • Adjusted leaf piles to yield snacks more frequently
  • Fixed game launch issues on Mac
  • Fixed an animation bug for the Enchanted Witch's Broom when client prediction is enabled
  • Fixed a bug where Rock Lobsters were not protected from acid rain
  • Added an optional run setting to read/write cluster folder files for modders

Buffs

  • Added a chance to obtain pumpkin bombs along with candy from the Pig King
  • Buffed leaf piles to allow more frequent snack acquisition

Bug fixes

  • Fixed game launch issues on Mac
  • Fixed an animation bug for the Enchanted Witch's Broom when client prediction is enabled
  • Fixed a bug where leaf piles could not be swept using the action button
  • Fixed a bug where Rock Lobsters were not protected from acid rain in the Lunar Grotto and Ancient Archives
  • Fixed a bug where the King of Science Machine skin became transparent when burned
