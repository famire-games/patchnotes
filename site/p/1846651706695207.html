Farming Simulator 25 Patch 1.25

Patch 1.25 for Farming Simulator 25 is now available, introducing animal workers, year-round vineyard planting, and numerous pack updates and bug fixes.

Key changes

  • Hire animal workers for horses and alpacas
  • Vineyards can now be planted all year round
  • New boundary painting for vineyards and olive orchards
  • Added progress of each construction step to Player HUD
  • Vehicle displays: dark mode for convenience screen and improved GPS icons

Bug fixes

  • Fixed the moon rising instead of the sun at the start of a day
  • Fixed the fence snapping angle
  • Fixed the stump cutter on trees that hadn’t been cut yet
  • Fixed hand tools after changing the player style
  • Fixed input bindings for the Hori truck control wheel
