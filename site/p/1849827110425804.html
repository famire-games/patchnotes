Dota 2 Gameplay Update 7.42

Patch 7.42 has been applied. Individual skill hotkey binding features have been added for Invoker, Rago, and Kez, alongside client and server performance improvements and numerous bug fixes.

Key changes

  • Added individual skill hotkey binding features for Invoker, Rago, and Kez
  • Added unit ability hotkey settings for specific summons and neutral creeps
  • Added an option to display silhouettes for units blocked by vision
  • Added 'Hand of Midas' category to Dota Plus gold earned breakdown
  • Improved client performance when generating illusions
  • Refactored unit behavior state machine for server performance

Bug fixes

  • Fixed an issue where Aghanim's Shard could be sold on the same frame it was delivered from the courier to the hero with a full inventory
  • Fixed an issue where other heroes' items could be moved to or taken from the stash
  • Fixed a bug where Beastmaster could permanently increase lane creep health and movement speed using specific traits, illusions, and disconnects
  • Fixed a bug where Meepo could generate infinite gold through a specific complex procedure
  • Fixed a crash occurring when the prime Meepo sells all Town Portal Scrolls
