November 23 (Mon) Seamless Patch Notice

A seamless patch was applied upon reconnecting after 7:38 PM on November 23. An issue where the CSAT Completion Commemorative Package could not be purchased in bulk and a currency display error in the Halloween item purchase popup have been fixed.

Key changes

  • Fixed issue with the CSAT Completion Commemorative Package bulk purchase button
  • Fixed currency display error when purchasing Halloween items

Bug fixes

  • Fixed an issue where the CSAT Completion Commemorative Package bulk purchase button did not work
  • Fixed an issue where the currency in the popup was displayed as 'Lucci' when purchasing Halloween items
