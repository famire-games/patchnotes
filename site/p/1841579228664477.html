Patchnotes 20.08.2026

Fish models have been improved, a new hotkey setting has been added, and spin fishing effectiveness has been adjusted. The game world has been reset across all water bodies, changing fish habitats and preferences.

Key changes

  • Improved fish models for Arctic Char, Ide, Burbot, Atlantic Salmon, and Blue Bream
  • Added 'Caught Fish Screen Hotkeys' setting
  • Lowest weight fish selected first when auto-filling crafting recipes from keepnet
  • Gameplay realism adjustments in Winding Rivulet, Sura River, Belaya River, Copper Lake, and Norwegian Sea
  • Adjustments to improve spin fishing effectiveness
  • Game world reset for all water bodies, changing fish habitats and bait/lure preferences

Bug fixes

  • Fixed gear ratio parameters only applying after restart when replacing reel mechanisms
  • Fixed issue where it was impossible to pick up a rod placed in a rod holder on a boat
