Nov 17 Non-Maintenance Patch Notice

A notice regarding the non-maintenance patch applied upon reconnecting after 4:00 PM on November 17. Fixes issues related to Mergetown, Fantasy Garden, and Ranch.

Key changes

  • Fixed image display issue for the 'Butter Cookie' block in Mergetown
  • Fixed issue where completed order boards would not change in Mergetown
  • Fixed harvest yield display bug after upgrading Black Soil in Fantasy Garden
  • Fixed incorrect level-up requirement descriptions for Ranch levels 58 and 60

Bug fixes

  • Fixed an issue where the image of the 'Butter Cookie' block in Mergetown was displayed incorrectly
  • Fixed an issue where completed order boards in Mergetown did not update
  • Fixed an issue in Fantasy Garden where harvest yields appeared as default plot amounts after upgrading to Black Soil
  • Fixed an issue where level-up requirement descriptions for Ranch levels 58 and 60 were incorrectly stated
