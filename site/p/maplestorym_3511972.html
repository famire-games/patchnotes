7/30 MapleStory M Patch Notice

The main screen, UI, hamburger menu, and scheduler functions have been extensively revamped, and skill quickslots and control methods have been improved. In addition, various in-game systems and conveniences such as quests, content, Force Fields, and Elite Dungeons have been improved.

Key changes

  • Completely revamped main screen and hamburger menu UI
  • Expanded scheduler system to support automatic progression of content, tasks, and bosses
  • Increased skill quickslots to 12 per page and added automatic preset feature
  • Separated exterior setting slots for coordi and medals/titles
  • Changed Elite Dungeons to single mode and added a dedicated shop
  • Improved Force Field UI and added party auto-join feature

Buffs

  • Overall increased jewel rewards obtained upon clearing Daily Dungeons
  • Changed jewel fusion success probability
  • Increased number of skill quickslots to 12 per page

Nerfs

  • Deleted Chaos Daily Dungeons
  • Adjusted required stats for some Star Force Fields and removed Lv. 50 achievement benefits (Star Force +5)

Bug fixes

  • Improved display rules for some red dots that did not disappear upon checking
  • Improved freedom of buff quickslot slot configuration and reset effect fixed slots
  • Changed Monster Park clear count limit to be character-based
  • Added adventure mission reset and skip features
  • Changed some content unlock requirements from quests to level achievements
