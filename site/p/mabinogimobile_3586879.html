Mabinogi Mobile · November 25, 2026

11/26 (Thu) Update Notes

The November 26 Mabinogi Mobile update introduces new appearance customization options, bug fixes, and balance adjustments for Memorial Saga Familiar skills. Additionally, fixes were applied to Nightmare Drill, Winter Snack Selection Basket, and Runda Abyss.

Key changes

  • Added new appearance customization options available upon rebirth
  • Fixed skill descriptions and effect errors for Memorial Saga Familiars
  • Fixed an error where the erosion gauge was reset during Nightmare Drill
  • Fixed an issue where the Winter Snack Selection Basket could not be purchased or registered on the Exchange
  • Fixed issues related to abnormal play clear records in Runda Abyss
  • Added Black Friday packages and the 'Finding Erinn's Essence' event

Buffs

  • Pledged Gardener Golem 'Fruit of Protection' shield value increased from 10% to 20%
  • Pledged Goblin Archer 'Poison Arrow' duration now correctly applies as 20 seconds matching the skill description
  • Pledged Stag 'Defense Instinct' defense increase value increased from 0.1 to 10%
  • Pledged Yellow Mushroom and Plump Mushroom poison duration increased from 1 second to 6 seconds

Nerfs

  • Pledged Yellow Mushroom and Plump Mushroom poison application chance decreased from 100% to 50%

Bug fixes

  • Fixed an issue where damage values in Familiar skill descriptions displayed as half of the actual damage dealt
  • Pledged Worker Beetle 'Flip' range adjusted from 5m to 3m
  • Removed unnecessary cooldown text from 'Self-Destruct' skill of Pledged Slime and Giant Infected Slime
  • Fixed an issue where the erosion gauge intermittently failed to reset during Nightmare Drill
  • Removed expiration date from Winter Snack Selection Basket, added selling functionality, and re-issued items to affected users
