Counter-Strike 2 Update

This Counter-Strike 2 update improves Retakes gameplay and adds/changes map scripting-related features.

Key changes

  • Instantly defuse the bomb in Retakes mode when defuse time and utility conditions are met
  • Reduced freeze time and round restart delay in Retakes mode
  • Added feature to request tricks by pinging chickens during freeze time
  • Chicken names are no longer displayed when setting custom item text
  • Added numerous new map scripting functions and exports
  • Renamed and migrated entity-related names of existing instance methods

Bug fixes

  • Added error reporting when calling invalid entity methods
  • Added ConnectOutput warning log when the target has no output of that name
