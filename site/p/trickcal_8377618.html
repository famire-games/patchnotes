October 29 Update Details

The October 29 update for Trickcal Re:Dive introduces a new Dimension Clash season and changes to the group assignment method, alongside the main story and the re-release theater. Additionally, convenience improvements and various bug fixes have been applied.

Key changes

  • Dimension Clash [Madness] season started and group assignment system revamped
  • Added Main Story Season 3 Chapter 8 and Season 1 Bonus Chapter
  • Re-released 3 Re-Release Theater themes and the 'Art's Bucks' selected theater themes
  • Improved Board Guide filter settings to persist in the Apostle List
  • Improved some standing motions for the Apostle Coffe
  • Added new Butter pickup recruitment, November attendance event, and new packages

Bug fixes

  • Fixed an issue where some areas of the Board Guide BETA could not be touched at certain resolutions
  • Fixed an issue where some furniture was applied abnormally when applying Coffe's Room package in the Cultist's Room
  • Fixed an issue where the lounge Apostle date count did not exceed a certain number of times
  • Fixed an awkward chapter notation in some story guide text
