Strinova April 16 Update

A new Demolition map 'Lebrun City' has been added, along with the 'Boom Fest' mode and soccer kit module in the Map Workshop. Character balance adjustments for Cielo, Bai Mo, and others, as well as weapon dispersion improvements, have also been implemented.

Key changes

  • Added new Demolition map 'Lebrun City'
  • Added Map Workshop 'Boom Fest' and soccer kit module
  • Expanded the card system and increased deck creation limit from 6 to 9
  • Adjusted balance for all weapons and some characters (Cielo, Bai Mo)
  • Hosted new events (Cosmic Invitation, Lebrun City Exploration, etc.)
  • Updated Hermes Shop with new skins and Orblight Resonance

Buffs

  • Increased XP acquisition speed when dealing damage in Superstring mode
  • Changed per-level stat scaling from +5% Daging to +5% weapon damage
  • Increased melee attack speed by 100% upon Sword Clash extreme burst
  • Increased damage propagation coefficient for Cielo's String Energy Network Awakening 3 (1.25 -> 1.33)
  • Increased damage reduction duration for Bai Mo's String Energy Network Awakening 2 (0.6s -> 0.75s)
  • Added a feature to generate an enhanced grenade at the remaining position upon returning after using Bai Mo's Ultimate

Nerfs

  • Modified Blast Fiend's self-destruction ultimate so that it can no longer trigger Armor Forger card effects
  • Decreased base weapon damage for Cielo's default weapon (136 -> 120, fire rate adjusted from 100 to 105)
  • Decreased stealth duration for Bai Mo's String Energy Network Awakening 3 (0.6s -> 0.5s)

Bug fixes

  • Fixed an issue where the damage multiplier setting for Map Workshop defense tower modules was not applied
  • Fixed an issue where Nobunaga's teleport cast time could be canceled by special controls
  • Fixed an issue where characters became stuck or invincible in certain areas (Euler Port, Abyssal Front, etc.)
  • Fixed abnormal pupil effects during Kanami's Azure Specter skin manifestation state
  • Fixed an issue where specific spray sounds played too loudly in the lobby preview
