Honkai: Star Rail · September 28, 2026

Version 4.6 Update Notice

Honkai: Star Rail Version 4.6 「Before the Moon Rises, Dance with the Beast」 has been updated. New Trailblaze Missions, character Pearl, Light Cones, costumes, and various events and system optimizations have been introduced.

Key changes

  • Added new Trailblaze Mission 「Astropolis」 - 「Before the Moon Rises, Dance with the Beast」
  • Added new 5-star character 「Pearl (Elation•Ice)」 and 5-star Light Cone 「Colors Dedicated to Tomorrow (Elation)」
  • Added new costumes for Hyacine and Evanesha
  • Started new events 「Love, Ghosts + Robots」 and 「Cosmic Fantasy Pet Land」
  • Added 'Cosmic Fantasy Pet' type and pet exchange/placement system
  • Added support for MetalFX and 120 FPS settings on iPhone 18 Pro series

Bug fixes

  • Fixed an issue where Aventurine•Wave did not correctly trigger Elation skills under certain conditions
  • Fixed an issue where Gilgamesh could not attack enemies under certain conditions after using his Technique
  • Fixed errors in applying certain faction affinities and equations in Currency War and Simulated Universe: Divergent Universe
  • Fixed abnormal character modeling, visual effects, motions, and camera directing in some content
  • Fixed and optimized errors in Japanese and Korean voiceovers and dialogue subtitle text
