MapleStory Worlds · July 29, 2026

7/30 (Thu) Update Patch Notice

A client update and bug fix maintenance for MapleStory Worlds will take place on Thursday, July 30, from 7:30 AM to 10:00 AM. Resolution ratio matching improvements during world play and avatar wearing errors will be fixed.

Key changes

  • Improved screen display to match the set resolution ratio during world play
  • Fixed an issue where other avatar items could not be worn after equipping ears, skin, or plastic surgery avatars
  • Fixed an issue where some UI did not display properly upon entering worlds
  • Fixed an issue where the camera capture function for profile editing on Android devices did not run
  • Fixed an issue where some buttons in the menu were not displayed when playing worlds in mobile portrait mode

Bug fixes

  • Fixed an issue where temporarily other avatar items could not be worn after equipping ears, skin, or plastic surgery avatars
  • Fixed an issue where some UI elements did not display properly upon entering worlds
  • Fixed an issue where the profile editing camera capture function did not run properly on Android devices
  • Fixed an issue where some buttons in the menu were not displayed properly when playing worlds in mobile portrait mode
