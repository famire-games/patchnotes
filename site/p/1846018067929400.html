The Witcher 3: Wild Hunt - Patch 5.01 is Live

Patch 5.01 is now available for The Witcher 3: Wild Hunt — Remastered. This update brings gameplay adjustments like damage reflection to Exploding Shield, fixes for blade oils, dodge delays, and various PC and UI bug fixes.

Key changes

  • Fixed Automatically Apply Blade Oils feature issue
  • Added damage reflection to the Exploding Shield skill
  • Visual adjustments including Bloom, Ray Tracing, and Path Tracing
  • PC-specific graphics settings and GPU selection fixes
  • Fixed My Rewards and Twitch/Bilibili Drops chest issue in Vizima
  • Added measures to address save file data issues

Buffs

  • Added damage reflection to the Exploding Shield skill

Bug fixes

  • Fixed an issue where Automatically Apply Blade Oils only worked if enabled during the current session
  • Fixed uncontrolled movement of player-controlled boats under specific circumstances
  • Fixed an issue where dodging could have an unintentionally delayed response
  • Fixed an issue where Geralt's Stamina was fully drained when sprinting and dodging simultaneously
  • Fixed an issue where the GTAO Quality setting would reset after restarting
