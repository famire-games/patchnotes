MapleStory Worlds · November 18, 2026

11/19 (Thu) Update Patch Information

The November 19 update for MapleStory Worlds added a free avatar random-equipping feature upon creating a new registration profile, and introduced duplicate purchase prevention and refund status display features for world products. Additionally, window resizing when entering vertical-mode worlds in Windows window mode has been improved, and several bugs have been fixed.

Key changes

  • Randomly equipped free avatar items and provided wardrobe upon creating a new profile
  • Added duplicate purchase prevention notices and refund progress status displays for world products
  • Provided notifications to buyers/sellers when payments are cancelled due to network timeout
  • Changed minimum/recommended specs for Mac OS on the official website to 12.0 or higher
  • Adjusted window size and position when entering vertical-mode worlds in Windows window mode
  • Fixed issues such as world names missing from the friend list and avatar motion errors

Bug fixes

  • Fixed an issue where the world name a friend was playing in was not displayed in the language being used in the friend list
  • Fixed an issue where motions or emotes of certain avatar items and resources were not displayed normally
  • Fixed an issue where animations that finished playing in avatar item details did not play again when clicked
  • Fixed an issue where moving to another world through the event menu within the world details page on the PC client was not possible
