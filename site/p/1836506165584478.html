Version 3.5 Update Guide

In Wuthering Waves Version 3.5, new Resonators Yangyang·Hyunryeong and Susa, alongside the Rover (Electro) attribute, have been added. Furthermore, a large wave of new regions, weapons, Echoes, main and exploration quests, along with various optimizations and events, have been introduced.

Key changes

  • Added 5-star Resonators Yangyang·Hyunryeong (Havoc/Sword) and Susa (Glacio/Rectifier)
  • Added Rover's new resonance attribute 'Electro'
  • Added 5-star weapons 'Blue Oath' and 'Dawn Herald'
  • Added new region 'Mongju' and related main/exploration quests
  • Added new Echoes, Sonata effects, and Tacet Fields
  • Added PC version XeSS 3 frame generation support and capacity optimization
