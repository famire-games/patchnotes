Marvel Rivals October 29, 2026 Patch Notes

A new patch for Marvel Rivals will be released on October 29, 2026, without downtime. It adds new shop bundles, the 'Night of Illusions' event, and fixes various hero and map bugs.

Key changes

  • Added new shop bundles and emotes for Winter Soldier, Storm, and Iron Man
  • Hosted new event 'Night of Illusions' (October 29 - December 31)
  • Fixed Gorr's out-of-bounds map bug
  • Fixed hero-related bugs for Rogue, Black Cat, and Invisible Woman
  • Fixed errors related to the Timesquare map and shop UI
  • Fixed bugs related to Moon Fate in Blood Hunt mode

Bug fixes

  • Fixed a bug where Gorr would fly out of bounds when using Shadow Harvest
  • Fixed costume modeling clipping issues for Rogue's X-Men '97 Season 2 costume
  • Fixed an issue where the icon above Black Cat's head disappeared in her Fatal Weaver costume
  • Fixed an error related to Black Cat's ultimate keybind
  • Fixed a bug related to Invisible Woman exiting invisibility
  • Fixed a map return error that occurred when selecting 'Play Again' after a Timesquare match
