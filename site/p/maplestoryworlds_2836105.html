4/24 (Thu) MapleStory Worlds Update Notice

The MapleStory Worlds version 1.24.0 update was released on April 24. It includes Traditional Chinese language support, coupon features, creator item refund request features, alongside various convenience improvements and bug fixes.

Key changes

  • Added 'Traditional Chinese' to the world and client supported languages
  • Added coupon code redemption and reward acquisition features (iOS users must use the official website)
  • Added creator-made product refund request feature (displayed in World Coin history for 7 days)
  • Profile pages can now be viewed by clicking the creator's name in the Avatar Shop
  • Check premium PC Bang connection status icons on the official website
  • Reward lists refresh immediately when the date changes while the PC Bang reward popup is active

Bug fixes

  • Fixed an issue where banned players attempting to enter the test server did not see the ban popup
  • Fixed an issue where World Coin balances occasionally displayed as negative numbers when moving to the lobby after entering a world play session on the official website
  • Fixed an issue where item names sold in in-world shops were translated based on the world language
