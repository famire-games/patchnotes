Factorio Versão 2.0.77 Estável Lançada

A versão 2.0.77 de Factorio foi lançada como estável, trazendo diversas correções de bugs e novas funcionalidades na API de script para criadores de mods. As correções incluem problemas de sobreposição de pods de carga e travamentos de insertores.

Principais mudanças

  • Versão 2.0.77 de Factorio lançada como estável
  • Várias correções de bugs e de falhas (crashes)
  • Adicionadas novas propriedades de leitura à API de script
  • Busca de texto completo adicionada ao site de documentação da API

Correções

  • Corrigido problema de sobreposição em pods de carga acoplados a foguetes
  • Corrigido travamento de insertores se a munição estragasse durante o movimento em direção a uma torre
  • Corrigido travamento de silos de foguete devido a alterações de mods
  • Corrigido travamento ao destruir entidades específicas sem uma fonte
  • Corrigido problema em que a rolagem de livros de blueprints na biblioteca pessoal não funcionava corretamente na latência do multijogador
